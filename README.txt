# Shreya Tai — Raksha Bandhan Surprise 💜

Open `index.html` in a browser to test the website.

## Add music
Put an emotional English MP3 in this folder and name it exactly:
`music.mp3`
Then the 🎵 button on the final screen will play/pause it.

## Publish it
The easiest free method is GitHub Pages:
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, the `images` folder, and optionally `music.mp3`.
3. In the repository, open Settings → Pages.
4. Select the main branch as the source and save.
5. GitHub will give you a public website link you can send to Shreya Tai.

The site is mobile-first and works without a backend.
